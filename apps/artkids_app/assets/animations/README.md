# 🎬 ArtKids Animations Assets

Thư mục lưu trữ các hoạt ảnh chuyển động 2D vector và hiệu ứng UI:

- `ai_generating.json` (Lottie) — Hoạt ảnh que đũa thần kỳ / chổi vẽ ma thuật hiển thị trong `AiLoadingWidget` khi chờ AI pipeline xử lý nét vẽ.
- `creature_lion.riv` (Rive) — Mô hình hoạt ảnh 2D State Machine của con vật (idle, walk, tap reaction).
- `congrats_confetti.json` (Lottie) — Pháo hoa chúc mừng khi bé mở khóa huy hiệu mới.

> **Lưu ý kỹ thuật**:
> - Rive (.riv) được ưu tiên hàng đầu nhờ hiệu năng 60 FPS cực mượt, tiêu tốn chỉ ~20MB RAM trên Android Emulator.
